# Xudaai 本地产品资料整理工具

Windows 桌面程序，把供应商提供的资料整理成统一的标准产品档案，人工复核后可上传到现有 Xudaai 产品资料库并建立索引。

## 支持的批次

- 一个供应商文件夹中包含多个产品文件夹。
- 一个批次文件夹中包含多个供应商，每家供应商有多个产品。
- 一个 Excel 工作簿包含多个供应商和多个产品行；每行都会进入产品清单，按产品名/SKU 尝试关联文件夹和文件。
- 名称未能自动匹配的产品，可在清单中为当前产品指定专属文件夹，或挑选多个分散文件。目录扫描上限默认 500，可在界面设置为 1–10000；单产品上传仍受服务端 250 文件限制。

## 使用步骤

1. 下载并运行 `product_importer/dist/Xudaai产品资料整理工具-AI对话版.exe`。
2. 在“资料与产品信息”页选择批次目录和可选 Excel，点击扫描；复核供应商、产品、资料来源和字段。
3. 在“AI 整理对话”页按当前选中的产品询问/整理资料；AI 生成的字段草稿由人工确认。
4. 在“生成与上传”页批量生成档案并上传索引。产品档案按“输出目录/供应商/产品”分组；逐项显示成功或失败。

源资料不会被修改。ZIP 包由使用者先解压；1688 页面由使用者下载成 Excel 和文件。启用 AI 时，解析后的文字资料会发送给所配置的模型服务。

完整字段、文件格式和限制见 [`product_importer/README.md`](product_importer/README.md)。源码及 Windows 打包说明也在 `product_importer/`。
