# Xudaai 本地产品资料整理工具

Windows 桌面程序，用于将供应商资料按“供应商 → 多个产品”整理成标准产品档案，人工复核后上传至现有 Xudaai 产品资料库并建立索引。

## 直接使用

下载 `product_importer/dist/Xudaai产品资料整理工具-AI对话版.exe`，双击运行。无需在使用电脑安装 Python。首次使用时填写现有 Xudaai 服务地址和登录凭证。

## 支持的批次结构

- 一个供应商文件夹下包含多个产品子文件夹。
- 一个批次文件夹下包含多个供应商文件夹，每家供应商有多个产品子文件夹。
- 一个 Excel 工作簿包含多个产品行，可含供应商名称、SKU、型号、价格等列；也可以只选择 Excel。
- 文件名包含产品名或 SKU 时尝试自动关联图片/资料；未匹配时可以人工指定产品专属文件夹和主图。

## 导入流程

1. 在“资料与产品信息”页选择供应商/批次文件夹或多产品 Excel，扫描后复核供应商和产品清单。
2. 选中产品，填写字段；在“AI 整理对话”页按当前产品询问资料、补字段或提出修正。字段变更需确认后才回填。
3. 在“生成与上传”页按供应商目录批量生成标准档案，并逐个上传、建立索引。结果列出成功和失败产品。

源文件不会被修改。1688 链接由使用者自行下载为 Excel 和文件后导入。启用 AI 时，解析出的文字会发送到所配置的模型服务。

## 源码和重新打包

源码、依赖和打包脚本在 `product_importer/`。从该文件夹运行 `build_windows.ps1` 可重新生成 exe；也可运行 `start_windows.bat` 在有 Python 3.11 的电脑上启动源码版。

上传需要目标 Xudaai 服务已部署 `/api/products/import` 接口。该接口保存每款产品记录和文件并建立索引。原 Xudaai ERP 项目已接入该接口。
