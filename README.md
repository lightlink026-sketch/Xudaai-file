# Xudaai 本地产品资料整理工具

Windows 桌面程序，把供应商提供的资料整理成统一的标准产品档案，人工复核后可上传到现有 Xudaai 产品资料库并建立索引。

## 支持的批次

- 一个供应商文件夹中包含多个产品文件夹。
- 一个批次文件夹中包含多个供应商，每家供应商有多个产品。
- 一个 Excel 工作簿包含多个供应商和多个产品行；每行都会进入产品清单，按产品名/SKU 尝试关联文件夹和文件。支持又拍下载目录、1688/OpenCLI Excel 和人工整理目录进入同一批次。
- 名称未能自动匹配的产品，可在清单中为当前产品指定专属文件夹，或挑选多个分散文件。目录扫描上限默认 500，可在界面设置为 1–30000；单产品上传仍受服务端 250 文件限制。

## 使用步骤

1. 下载并运行 `product_importer/dist/Xudaai产品资料整理工具-AI对话版.exe`。
2. 在“资料与产品信息”页导入批次目录和/或 Excel，点击扫描；又拍可从“又拍链接下载”按钮进入。产品列表按供应商和产品拆分。
3. 在“AI 整理对话”页按当前选中的产品询问/整理资料；AI 字段草稿必须人工确认后才回填，模型地址/名称保存在本机，API Key 仅存于运行内存。
4. 产品缺少名称、供应商、单价、箱规尺寸或单箱毛重时标记“待补资料”，生成档案仍会把具体缺项写入 JSON，便于之后补录；齐全档案标记为待复核。
5. 在“生成与上传”页可创建统一文件夹和 Excel 模板，再批量生成档案并上传索引。产品档案按“输出目录/供应商/产品”分组；逐项显示成功或失败。又拍详情回写保留已有非空人工数据，刷新相册不删除 `商品详情.txt`。源码随项目一起提供。

源资料不会被修改。ZIP 包由使用者先解压；1688 页面由使用者下载成 Excel 和文件。启用 AI 时，解析后的文字资料会发送给所配置的模型服务。

完整字段、文件格式和限制见 [`product_importer/README.md`](product_importer/README.md)。源码及 Windows 打包说明也在 `product_importer/`。
