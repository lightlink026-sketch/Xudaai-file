# Xudaai 产品资料整理工具

Windows 本地桌面工具。一次整理一个批次，支持一个供应商目录下多款产品，也支持一个批次目录下多个供应商、每家多款产品。支持三种资料入口：又拍链接下载、1688/OpenCLI 导出的 Excel、人工整理的文件夹/文件。供应商 ZIP 包由员工先在本机解压。

主界面标题栏右侧按钮和顶部“工具”菜单都可打开 Yupoo 相册下载与商品报价表功能：批量下载相册图片、维护下载总记录、生成/回写 Excel、按 Excel 内容和顺序生成 PDF。该功能的 Python 源码与证书模块一并包含在 `yupoo_tool.py`、`ca_bundle.py` 中，作为主程序内的窗口运行，不依赖旁置的 Yupoo EXE。

## 本地运行

需要 Python 3.11+。双击 `start_windows.bat` 会建立独立虚拟环境、安装整理工具依赖并启动窗口。

## 打包为 Windows 程序

在 Windows 开发机双击或运行 `build_windows.ps1`。生成的单文件程序位于 `dist/Xudaai产品资料整理工具-AI对话版.exe`，可复制到团队电脑运行。每台电脑可独立整理任务，不需要连接 NAS 才能扫描或编辑资料。

## 操作流程

1. 在“资料与产品信息”中选择供应商/产品目录，选择 1688/OpenCLI 导出的 Excel；也可以点“又拍链接下载”抓取相册后，再选择其供应商目录。支持一个批次多供应商、每个供应商多产品。一个供应商目录里的产品子目录会分别识别；不会只取前 200 款。扫描按钮旁可设置目录文件扫描上限（默认 500，可调 1–30000），设置会保存在本机。
2. 多产品 Excel 需要“产品名称/品名”等名称列；可选“供应商/供应商名称”“SKU”“型号”“价格”等列。每个产品行都会保留在批次清单中；产品目录或文件名按名称/SKU关联，未匹配的行也可稍后手动指定资料。
3. 选中清单中的产品，填写字段或在“AI 整理对话”中逐款询问、补充和更正。AI 模型地址/名称可保存到本机设置，API Key 仅存于当前运行内存。AI 提取和对话给出的字段都需人工确认才回填。
4. 图片和资料优先按产品名称/SKU匹配文件名；未匹配时，选中清单产品后可用“指定文件夹”关联整目录，或用“指定文件”挑选分散的图片、视频和文档，再选择主图。
5. 产品名称、供应商、采购单价、箱规尺寸、单箱毛重为关键信息。缺失时清单标记“待补资料”，仍可先生成和上传；缺项会写入产品档案 JSON 的 `missing_fields`，状态为 `needs_info`，方便后续筛选补录。信息齐全的档案状态为 `ready_for_review`。
6. 每个产品单独生成标准档案并保存到 `输出目录/供应商/产品档案/`；上传时逐个写入产品记录并建立索引，结束后显示成功/失败清单。

输出目录包含 `产品档案.json`、`图片/主图`、`图片/副图`、`视频/`、`原始资料/` 和保留用的 `规格/` 目录。图片/视频会整理到标准媒体目录；原始 Excel、PDF、DOCX、CSV、TXT、Markdown、PPTX/JSON 等资料原样复制到原始资料目录。输出中的 JSON 会被资料索引检索。

## Yupoo 工具与资料保留

点击“又拍链接下载”会在同一应用中打开相册工具窗口。输入多个供应商的又拍链接时，按网站账号自动分开供应商目录；每个相册保留链接、下载信息、图片、报价 Excel 和 `商品详情.txt`。Excel 字段包含价格、MOQ、箱规、CBM、单箱毛重/净重。回写时以相册 ID 优先匹配；已有非空人工字段优先保留，Excel 中空白值不会清空旧值。重新下载只更新程序管理的图片及信息文件，不删除 `商品详情.txt`。

又拍文件夹、1688 Excel 和人工资料进入同一批次清单后，最终都生成相同的标准档案目录。在“生成与上传”页可生成空白标准资料模板。对应实现代码在 `yupoo_tool.py`，内置 CA 证书在 `ca_bundle.py`；打包依赖列于同一目录的 `requirements.txt`。

## 数据和隐私

- 源文件不被修改。生成的标准档案先保存在员工选择的本地输出目录。
- 只有点击上传后，产品包才发送到现有资料库。服务器为每个档案保存产品记录并索引支持的文件。
- AI 提取可选。启用时，解析出的文档文字会发送到所填模型服务；API Key 仅在当前运行内存中使用，不写入配置文件。未启用 AI 时可完全手工整理。
- 对话中的字段建议需逐次人工确认后才回填；AI 不会自动覆盖已填写内容，也不会自动上传。聊天记录只保存在本次工具运行内存。
- 软件地址、账号、输出目录等非密钥偏好写入用户目录下的 `.xudaai-product-importer.json`；密码和 API Key 不持久化。
- 上传使用现有资料库的 HTTP Basic 登录配置。大量/大型视频上传受服务器限制：单文件 250 MB，单个产品包最多 250 个文件、总计 750 MB；目录扫描上限可自行调高，但超过产品包限制时不能直接上传。

## 当前范围

用户自行解压 ZIP、下载 1688 文件。多产品 Excel 依据表头逐行识别；供应商和产品对应关系需人工核对。Excel 中每个产品行都会进入清单，即使没有同名目录也可以只凭表格建档；无法按名称/SKU匹配的图片/资料，可手工指定产品资料文件夹或逐个指定文件。AI 处理解析出的文字，不直接视觉识别图片。批次上传逐款执行；如果个别产品失败，成功记录不会自动回滚。
