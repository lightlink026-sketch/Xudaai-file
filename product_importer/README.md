# Xudaai 产品资料整理工具

Windows 本地桌面工具。每个供应商产品目录单独整理；供应商 ZIP 包由员工先在本机解压，再选择解压后的产品文件夹。1688 资料由员工下载成 Excel/文件后与产品文件夹一起导入。

## 本地运行

需要 Python 3.11+。双击 `start_windows.bat` 会建立独立虚拟环境、安装整理工具依赖并启动窗口。

## 打包为 Windows 程序

在 Windows 开发机双击或运行 `build_windows.ps1`。生成的单文件程序位于 `dist/Xudaai产品资料整理工具.exe`，可复制到团队电脑运行。每台电脑可独立整理任务，不需要连接 NAS 才能扫描或编辑资料。

## 操作流程

1. 在供应商资料中选择一个产品文件夹；可额外选择一份 Excel。工具只读取和复制资料，不会改动来源文件夹。
2. 点“扫描并读取资料”，再手工填写或使用兼容 OpenAI Chat Completions 的模型提取字段。AI 只生成草稿，不会自动确认。
3. 选择主图，检查名称、型号、供应商、价格、MOQ、单位、箱规、单箱装量、CBM、毛/净重。
4. 生成标准档案后检查输出目录；确认后输入现有软件地址和需要的登录凭证，点“上传并建立索引”。
5. 成功后，现有软件会将文件放到 `产品资料/<产品编号>/`、保存产品档案记录，并按支持格式建立索引。

输出目录包含 `产品档案.json`、`图片/主图`、`图片/副图`、`视频/`、`原始资料/` 和保留用的 `规格/` 目录。图片/视频会整理到标准媒体目录；原始 Excel、PDF、DOCX、CSV、TXT、Markdown、PPTX/JSON 等资料原样复制到原始资料目录。输出中的 JSON 会被资料索引检索。

## 数据和隐私

- 源文件不被修改。生成的标准档案先保存在员工选择的本地输出目录。
- 只有点击上传后，产品包才发送到现有资料库。服务器为每个档案保存产品记录并索引支持的文件。
- AI 提取可选。启用时，解析出的文档文字会发送到所填模型服务；API Key 仅在当前运行内存中使用，不写入配置文件。未启用 AI 时可完全手工整理。
- 软件地址、账号、输出目录等非密钥偏好写入用户目录下的 `.xudaai-product-importer.json`；密码和 API Key 不持久化。
- 上传使用现有资料库的 HTTP Basic 登录配置。大量/大型视频上传受服务器限制：单文件 250 MB，单个产品包总计 750 MB。

## 当前范围

本版本按“一次一个产品文件夹”整理。Excel 可在该文件夹内，也可以单独选择作为补充来源。用户自行解压 ZIP、下载 1688 文件。网页、图片不会被 AI 自动识别；主图由人工选择，AI 仅处理支持格式中的可提取文本。音视频可随档案上传，服务端是否能转写取决于现有音视频索引配置。
