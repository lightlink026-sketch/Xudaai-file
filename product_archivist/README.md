# Xudaai 产品档案工作台

全新本地桌面软件，不加载旧版主界面、旧工作流或旧版任务数据库。各采集器统一生成产品档案，进入同一复核和上传流程。

## 页面

- 顶部横向主菜单；左侧 AI 助手可管理模型配置与多轮对话，右侧显示当前模块操作。
- 模型配置支持查看、新增、修改、删除和切换；API Key 使用 Windows DPAPI 加密保存在当前用户本机。
- 又拍页内嵌原采集界面，保留 Excel、PDF、强制更新、详情回写等按钮；又拍、1688、Excel/本地来源各显示一次。
- 采集与导入：内嵌 Yupoo、OpenCLI 1688、Excel、本地多供应商目录。
- 产品复核：字段编辑和缺项检查；原始价格进入成本价，支持批量固定加价或百分比加价生成批发价，也可批量将批发价同步为成本价。
- 标准档案与上传：按标准产品目录生成并上传。
- 任务中心：下载/导入与上传分栏，支持查询、分页、删除任务记录。
- 设置：AI 和 Xudaai 连接、本地输出位置。

启动后进入“采集与导入”。AI 助手固定在左侧，随右侧当前模块切换上下文，并可新增、切换和删除对话。

## 运行与构建

开发运行：在仓库虚拟环境安装 requirements.txt 后运行 python main.py。

Windows 打包：运行 build_windows.ps1，输出 dist/Xudaai产品档案工作台.exe。

## 本地数据

档案默认输出到“文档/Xudaai产品档案”。独立任务库为 .xudaai-archivist-tasks.sqlite3，来源索引为 .xudaai-archivist-sources.sqlite3。模型密钥只保留在运行内存；模型地址和名称可保存到用户配置。

上传接口使用 Xudaai 的 /api/products/import。服务端限制单个产品最多 250 个文件、单文件 250 MB、单产品总量 750 MB。

## 标准目录

每款产品独立目录，供应商作为上级分组：供应商/P-编号-产品名/。目录包含产品档案.json、图片/、视频/、规格与包装/、资质与说明/；不保存又拍原始下载目录或原始资料副本。

产品档案 JSON 保存稳定产品 ID、供应商和商品字段、来源、字段证据、媒体清单、缺项及审核状态。未知值留空；重新采集不能静默覆盖已确认的人工字段。

## 当前联调边界

Yupoo 采集器直接嵌入其原有完整界面和处理流程，源码依据 `D:\ruanjian\Yupoo桌面工具\app.py`；不会另开桌面工具窗口。采集完成后自动把相册和详情转换为标准产品目录，补录字段保存在产品档案.json；确认完整的下载才替换图片，未完成下载保留上一版图片。转换成功后删除临时原始下载目录，任务中心指向标准档案。

1688 链接支持每行一个批量采集；可在 1688 页选择本机 `opencli.exe` / `.cmd` / `.bat`，点击“检查并启动”验证命令，并保存路径供后续使用。也可在 AI 助手粘贴单个链接，确认后调用本机 OpenCLIApp 的 `1688 item` 与 `1688 download` 命令。保持 1688 登录会话有效。店铺列表和商品详情是不同采集模式，当前链接入口针对商品详情页。

真实供应商账号和 Xudaai 服务端联调需在目标电脑确认登录状态和接口更新语义。
