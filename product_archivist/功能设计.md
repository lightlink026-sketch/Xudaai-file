# Xudaai 产品档案工作台 — 产品与功能设计

## 产品目标

不论资料来自 Yupoo、1688、Excel 或人工整理目录，都必须生成同一套产品档案。每个入口将资料映射到标准目录和产品档案.json，再由用户复核并上传至 Xudaai。又拍原始下载目录是临时区，转换成功后删除，不作为兼容档案保留。

## 主流程

工作台 → 采集与导入 → 产品复核 → 标准档案生成 → 上传 → 任务中心
                           ↕
                        AI 助手

1. 用户选择 Yupoo、1688/OpenCLI、Excel 或本地目录入口。
2. 软件创建可查询的下载/导入任务；来源解析器识别供应商、产品和资料关系。
3. 所有来源形成同一个“批次—供应商—产品”工作清单。
4. 产品复核显示字段、原始来源、主图和缺项。AI 只给有证据的建议，不自行猜值或静默覆盖。
5. 档案生成器按统一 schema 写入本地产品目录。
6. 用户选择产品上传；上传任务记录每个产品结果，可重试失败产品。

## 页面和职责

- 顶部横向主菜单；模块 AI 助手固定显示在左侧，右侧展示当前模块操作。助手随模块切换上下文，支持新增、切换和删除对话。
- AI 模型配置可查看、新增、修改、删除和切换；API Key 使用 Windows 用户级加密保存在本机。
- 采集与导入：Yupoo、1688/OpenCLI、Excel、本地目录四种来源。所有入口共用批次输出。
- 1688 采集支持多行链接逐条批量执行，也支持 AI 助手分析单个链接、经用户确认后调用本机 OpenCLIApp。用户可配置 OpenCLIApp 命令路径、检查启动状态；采集器不允许模型直接执行任意 shell 命令。
- Yupoo 直接集成 `D:\ruanjian\Yupoo桌面工具\app.py` 的采集处理逻辑与原有界面，不启动独立窗口。保留 Excel、PDF、强制更新、商品详情回写等按钮。采集先写入临时区，随后按相册 ID 转换为标准产品目录；来源相册 URL、价格、MOQ、箱规、重量和尺码进入产品档案.json，图片进入标准图片目录。临时下载文件仅在转换成功后删除。
- 对话支持连续多轮；产品字段建议需基于证据，且经用户确认后写入。
- 产品复核：按供应商和产品查看、编辑、筛选缺项；原始价格映射为成本价，支持按固定金额或百分比批量生成批发价，或将批发价同步为成本价；保留字段证据。
- 标准档案与上传：生成标准目录，检查缺项和文件数，再上传到 Xudaai。
- 任务中心：下载/导入与上传分栏，统一搜索、分页、打开目录、重试与删除任务记录。
- 设置：模型地址、模型名称、API Key、本地输出目录、Xudaai URL 和账号。

## 标准档案

每款产品一个目录，供应商作为上级分组：

供应商/
└─ P-编号-产品名/
   ├─ 产品档案.json
   ├─ 图片/                 # 主图和副图，角色记入 JSON
   ├─ 视频/
   ├─ 规格与包装/
   └─ 资质与说明/

产品档案.json 是产品字段和文件清单的机器主档案，保存 schema 版本、稳定产品 ID、产品编号、供应商、价格、MOQ、规格、箱规、重量、媒体清单、来源 URL、字段来源、缺失字段和复核状态。标准目录不要求“原始资料”副本；商品详情中确认的字段以 JSON 为准。未知值留空并标记，不以常识补造。

## 合并和重采规则

- 采集批次与产品使用来源商品 ID/相册 ID 建立关联。
- 重采不直接覆盖已确认字段；空字段可补，新旧冲突进入人工核对。
- 完整的又拍重采更新图片；人工确认的非空字段和标准目录中的规格/资质附件保留。下载不完整时保留上一版图片。
- AI 建议需预览、确认后写入字段，并记来源。
- 删除任务记录与删除本地目录是独立操作；默认仅删记录。

## 数据与任务

- 任务表保存任务类型、来源、输入链接/路径、状态、产品数、输出目录、结果详情及时间。
- 任务中心的下载栏包括采集和导入；上传栏包括 Xudaai 上传。
- 本地标准档案是上传重试的依据，上传任务保留逐产品成功/失败明细。
- 运行数据库与旧版文件名隔离，不导入旧界面状态或旧版批次。

## 交付检查点

1. 以真实 Yupoo 类目/相册确认采集结果能生成产品复核行。
2. 以本机 OpenCLI 的 1688 商品页确认字段、图片和输出归属。
3. 用多供应商、多产品 Excel 和嵌套人工目录验证归类。
4. 用 Xudaai API 确认产品目录、JSON 字段、索引与更新规则。
5. 验证重复采集不覆盖人工补录，失败上传可从任务中心重试。

第 4、5 项依赖真实账号和服务端数据，需在部署环境完成联调。
